Install in 4 steps

1

Unzip the file

Find the downloaded gowarm-linkedin-ext-latest.zip in your Downloads folder and unzip it. You'll end up with a folder called gowarm-linkedin-ext — remember where it is, you'll point Chrome at it in a moment.

Don't move or delete the folder after installing. Chrome keeps a live reference to wherever you unzipped it. If the folder disappears, the extension stops working.
2

Open Chrome's extensions page

In Chrome, type chrome://extensions into the address bar and press Enter. You can also reach it via Menu → Extensions → Manage Extensions.

3

Turn on Developer mode

In the top-right corner of the extensions page, flip the Developer mode toggle on. Three new buttons appear at the top of the page.

Chrome will show a small "Developer mode is on" reminder each time it restarts. That's normal — it just means the browser is running an extension that wasn't installed through the Chrome Web Store.
4

Load the extension

Click Load unpacked, then select the gowarm-linkedin-ext folder you unzipped in step 1 (the one with manifest.json inside).

The GoWarmCRM card will appear on the extensions page. Pin the icon to your toolbar for easy access: click the puzzle-piece icon at the top of Chrome, then the pin next to GoWarmCRM.

Sign in

Open app.gowarmcrm.com and sign in to your account. The extension picks up your session automatically — there's no token to copy or API key to configure.

Visit any LinkedIn profile (linkedin.com/in/<name>) and the GoWarm panel will appear on the right.

Updating to a new version

When a new version is available, the extension popup shows a banner with a Reload button. To update:

  1. Download the new zip from this page.
  2. Unzip it and replace the old gowarm-linkedin-ext folder with the new one (use the same location).
  3. Open the GoWarmCRM extension popup and click Reload extension in the update banner.

Your sign-in stays — you don't have to log in again. If the Reload button isn't visible (older versions before 1.7.9), you can still update the old way: go to chrome://extensions and click the refresh icon on the GoWarmCRM card.

Troubleshooting

The panel doesn't appear on a LinkedIn profile
Make sure you're on a profile URL — linkedin.com/in/<name> — and not the LinkedIn feed, search, or messaging pages. Refresh the page. If it's still missing, check that the extension is enabled at chrome://extensions.
The popup says "Not connected"
Open app.gowarmcrm.com in another tab and sign in. Then click the extension icon again — it should switch to "Connected" within a few seconds.
A prospect exists in GoWarmCRM but the panel says "Not in your CRM"
The extension matches by LinkedIn URL. Open the prospect in GoWarmCRM and make sure the LinkedIn URL field is set to the full profile URL (https://www.linkedin.com/in/<name>). Watch for trailing slashes or query strings.
Chrome says the folder is missing or the extension failed to load
Chrome keeps a path reference to wherever you unzipped the folder. If you moved or deleted it, re-unzip the latest download in a stable location (e.g. ~/Documents/gowarm-linkedin-ext/), then load it again from chrome://extensions → Load unpacked.
I need to share a diagnostic with support
Open any LinkedIn profile, press F12 to open Chrome DevTools, switch to the Console tab, and run: 
copy(JSON.stringify(await __gowarmCaptureDebug(), null, 2))
That copies a diagnostic snapshot to your clipboard. Paste it into your support message.
